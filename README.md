# Site_Athar — Personal Site

This repository contains a Vite + React + Tailwind starter for a professional personal website focused on AI engineering, campaign analytics and strategic digital products.

Getting started

1. Install dependencies:

```
npm install
```

2. Run locally:

```
npm run dev
```

3. Build for production:

```
npm run build
```

Deploy to Cloudflare Pages

- Push this repository to GitHub.
- Create a Cloudflare Pages project and connect the GitHub repo.
- Use the build command `npm run build` and the build output directory `dist`.

Recommendations

- Customize `src/App.jsx` and `src/components/*` with real content, projects and links.
- Add a `CNAME` if you use a custom domain and configure it in Cloudflare Pages.
